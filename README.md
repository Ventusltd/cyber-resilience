# Cyber resilience

Single-party dependency of global finance, energy and other critical systems.

This repository records evidence and proposals on concentration risk, operational resilience, open-source alternatives, and the need for independently recoverable digital infrastructure.

## Research and public statements

- [13 November 2026 — Cloud outages, the Binance theft, and distributed resilience](research/2026-11-13-concentration-risk.md): fact-checked commentary, limitations and primary sources.

**Scope:** These notes distinguish documented incidents from proposed remedies. Open source, distributed version control, and multi-provider arrangements each help in different ways; none alone proves security, authenticity or resilience.
